Evidence and word list

How I checked this, where each fact came from, and what the technical words mean.

Word list

DecompileTurning a mod's finished program file back into readable code. It is like working out a recipe from the cake. The steps survive and the author's notes do not.
HarmonyThe standard tool mods use to add patches to the game.
PrepatcherA helper mod that adds extra storage slots to the game's objects. MultiFloors uses it for fast lookups. Its author says the 1.7 game now includes this ability.
Patch (prefix, postfix, finalizer)A step added before a game rule, after it, or as clean-up that runs even after a failure.
TranspilerA patch that rewrites the inside of a game rule.
Empty catchThe "empty error trap" in this report. Code that catches a failure and does nothing with it.
WorkGiverOne job type on the notice board. The base game defines 97.
RegionA patch of connected cells. The game uses regions to answer "can I reach that?" without walking the whole route.
PathfindingWorking out the actual walking route on a map.
TPSTicks per second, the heartbeat rate. 60 is the target at normal speed.
Vibe codingAn informal, often critical term for making software with AI while reading little of what it writes. It does not describe a test you can run on the code.

How I checked

  1. Read the public Steam pages, changelogs, and bug threads, using your browser for pages that blocked automated reading.
  2. Downloaded the mods anonymously with SteamCMD into a temporary folder. Nothing went into your game's Mods folder, your subscriptions, or your mod list. I did not start the game. Your installed MultiFloors, in C:\SteamLibrary\steamapps\workshop\content\294100\3384660931, matches the analysed copy file for file: all 304 files have the same SHA-256 hash.
  3. Decompiled the main file of each mod with ilspycmd, including your own built ZLevels.dll, so all five counts use the same method.
  4. Sent one reader through each codebase with the same questions. Each had to cite file and line.
  5. Rechecked the claims this report leans on against the code myself. Those are listed below. The remaining citations come from the readers and I did not re-read each one.
