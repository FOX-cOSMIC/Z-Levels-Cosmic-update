Your port is one of the smaller codebases here, with about the same number of patches as MultiFloors. Its problem is where those patches sit, and these counts cannot show that. They show size and risk. None of them measures speed.

The counts

All five were counted the same way, from each mod's main compiled file turned back into code, so comments do not affect the totals. MultiFloors and True Z-Levels keep add-on code for other mods in separate files, which are not counted here. For MultiFloors at 1.6, that is 9 files with 1,212 lines and 8 patches, each loaded only if you have the matching mod. Z-Levels' optional cooling module is also left out.

What players report

These are short samples from public pages, not statistics.

  • Z-Levels, 2020. "They know there's a storage but can't find the route." A second player saw colonists stop and stand idle after a new floor was generated.
  • MultiFloors. Items keep moving between floors when the target floor has no space, and storage rules can be ignored across floors. One comment reports getting stuck at world creation on 1.7 and another reports it working with Prepatcher switched off. The bug thread has 522 replies.
  • As Above So Below II. One player says hunting on an underground floor makes the game "stutter." The author's own number is "about 2% of frame budget on a 96 colonist test colony, holding 60 fps." The mod ships no data behind that number.
