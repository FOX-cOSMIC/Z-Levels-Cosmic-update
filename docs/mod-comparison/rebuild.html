Does Z-Levels need a rebuild?

Part of it does. Think of a house with sound walls and bad plumbing. You replace the plumbing and keep the house. First, measure how bad the plumbing is, because nobody has.

What is sound

These have passing test runs in your repository. The runner starts the real game with a new colony, carries out each step, and records the result. The repository keeps 568 run folders, including failed runs.

  • Generating floors above and below, and walking the stairs both ways
  • Hauling, mining, and building on another floor, with the colonist choosing the work
  • Power and reactor cooling across floors
  • The vault pocket, including saving and reloading it
  • A staircase destroyed by damage, which used to crash

Your port has fixed real faults too: rivers, a stairs crash, unreachable storage, stale map records, and fighting errors. A rewrite has to earn all of that again.

So is it "very buggy"?

In places, and some of it is simply unknown. These are from your own test report and roadmap.

  • Failures with no known cause. One cross-floor hauling timeout and a campfire failure came back in some runs and not others.
  • Never tested. Food, rest, and fun across floors have no scenario, because the tests hold those needs full. Fighting, raids, right-click orders, and other DLC are also untested.
  • Known and not fixed. The stranded colonist below, storage on other floors that nobody checks can be reached, and insects that the game's letter says tunnel up but never do.

Decision for you

D1. How much of Z-Levels should be rebuilt?

A. Measure, then rebuild the job search in place (Recommended)

Changes
Adds a speed test to the existing runner. Then replaces the worst parts of JobPatches.cs (2,284 lines) and ReachAndReservationPatches.cs, and adds a lighter update for empty floors. The vault, cooling, stairs, generation, and test runner stay.
Trade-off
You keep working features and test evidence, but you also keep separate maps and their memory cost.

B. Rewrite the whole mod around one map

Changes
Replaces about 15,000 lines. As Above So Below II shows the likely scale, at 55,842 lines and about 295 patches. Vault, cooling, and most test scenarios get rebuilt.
Trade-off
Removes the separate-map costs and carried-job problems, but creates a new class of faults, such as explosions and gas crossing between floors, and competes with a mod that is already out.

C. Stop the port and build add-ons for another mod

Changes
Moves your vault and cooling ideas to add-ons for MultiFloors or As Above So Below II. Z-Levels stops at its current state.
Trade-off
Least code to own, but neither mod publishes source I could find, so you would depend on their authors. MultiFloors has no official 1.7 version yet.

If you do not answer: I change nothing in the mod. The report is finished without this answer, and the speed test and all rebuild work wait for your decision.

The test that settles the lag question

Before changing any code, I would add a speed scenario to the test runner, in its isolated save folder as usual.

  • Run new colonies of 10 and 30 colonists, on 1, 2, and 5 floors, with no work available and with plenty of work.
  • Record heartbeats per second, and the time spent inside the job search.
  • Compare plain RimWorld, your port, and As Above So Below II. Add MultiFloors if it runs on 1.7.4998.
  • Rerun after each fix, so every change has a before and after number.

If the numbers show the lag is small, this page's priorities change, and the bugs come ahead of speed.

Order of work under option A

  1. Add the speed test and record a baseline.
  2. Make the cheap fixes: stop writing unread log lines, restore the graphics shortcut, and remove dead code.
  3. Add safety steps so a failure cannot strand a colonist.
  4. Change the job search to read the colonist's own floor first, and look elsewhere only when that floor has nothing. Add a pause before an idle colonist searches again.
  5. Fix the floors-inside-floors loop in hauling.
  6. Give floors nobody is using a lighter update, then check that fires, plants, and temperature still work there.
  7. Rerun the full test set and the speed test after each step.
