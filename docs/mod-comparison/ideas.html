Ideas from MultiFloors

The most valuable idea is the simplest: let the game run its normal job search, and look at other floors only when that search finds nothing. That one change could remove about 330 lines of stale copied code and most of the extra searching.

I compared each idea with your current code, so everything here is a real gap. MultiFloors has no license I could find, so these are ideas to rebuild in your own code, never code to copy. None has been built or timed. Each needs a test that fails first and passes after, as your project rules require.

Game events to check

MultiFloors has a patch for each of these. Your code may already be fine, so test first, and fix only what fails.

  • Parties, weddings, rituals, and title ceremonies held on another floor
  • Alerts and mood thoughts that assume everyone is on one map, such as lovers sleeping near each other
  • Falling objects breaking every roof above their landing spot
  • Thieves and kidnappers carrying their target down to the ground before leaving
  • Children's behaviour, mech charging, and roping animals from another floor

What not to copy

  • No fighting across floors. MultiFloors left it out. Your code has it, though it is untested. Testing it is worth more than removing it.
  • No colonists in the view below. MultiFloors' setting says pawns are not visible from above. Yours draws them, which is a real advantage, so keep it. Its idea of drawing only the uncovered areas is still useful.
  • Rewriting the game's text. MultiFloors has 46 of these patches, which is why game updates can hurt it. Add as few as you can.
  • Unlimited idle searches. An idle colonist still reads every floor in MultiFloors. Add a pause before they search again, which goes further than MultiFloors does.
