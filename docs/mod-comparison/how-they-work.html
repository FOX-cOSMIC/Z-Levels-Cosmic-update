How each mod works

RimWorld was built for one flat map. Every floor mod has to trick the game into handling a building with more than one storey, and each trick has a different price.

Four ideas you need first

The map is a game board

The game keeps one board per location, with its own lists of who is standing where, what is stored, and what needs doing. Each board costs memory and work to keep updated.

A tick is a heartbeat

At normal speed the game updates everything 60 times a second. If one update takes too long, the game runs slower. That is what players call lag.

A patch is a sticky note

Mods cannot edit the game, so they stick notes on its rulebook: "before you do this, also do that." A note on a page read once a minute costs nothing. A note on a page read thousands of times a second can slow the whole game.

Hot code is that busy page

Coders call the most-read pages "hot." Examples are "can this colonist reach that item?" and "is someone already using it?" Where a mod puts its notes matters more than how many notes it has.

How each mod builds a floor

This is the biggest design choice, and it is close to impossible to change later. Your port and MultiFloors chose separate boards. As Above So Below II and True Z-Levels chose one board.

What happens when a colonist needs a job

Picture each floor having a notice board with a list of job types: firefighting, doctor, building, hauling, and so on. The base game defines 97 of these. When a colonist finishes a task, they read the list top to bottom until they find work. This search happens constantly, so it is the best place to look for lag.

Z-Levels and MultiFloors both use the same trick while searching. They briefly pretend the colonist is standing on the other floor, ask the game's normal questions, and put the colonist back. So that trick is not what separates them. It is two quick changes of a value, and it is cheap. What separates them is how many times they run it, and where.

How each mod changes the rulebook

Sticky note (normal patch)

Adds a step before or after a rule. It usually survives a game update. All five mods use these.

Editing the page (transpiler)

Rewrites words inside a rule. It is powerful and light at runtime, and it breaks when the game reprints that page. MultiFloors has 46 of these, As Above 19, Z-Levels 1.

Photocopying the chapter

Copies a whole rule into the mod and edits the copy. Z-Levels does this for about 1,000 lines, including the job search, storage, bills, and food. When the game changes, the copy goes stale without any warning.

The staleness has already happened. The original 1.7 job search has newer checks that the Z-Levels copy lacks, because it was copied from a much older game version. Details are on the rebuild page.

When something goes wrong

An error trap with nothing inside is like a smoke alarm with no battery. The fire still happens, and nobody hears about it.
